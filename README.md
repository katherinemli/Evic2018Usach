# EVIC 2018 — Conference Website

**[Français](#français) · [English](#english)**

## Français

Site Web d'une seule page pour **EVIC 2018**, un congrès scientifique tenu à l'Universidad de Santiago de Chile (USACH). Il présente l'événement, les conférenciers invités, le programme, le concours et le lieu.

### Points forts
- SPA Vue 2 avec Vue Router et navigation à défilement fluide entre les sections
- Données des conférenciers et du programme servies par **Firebase** (VueFire), pour que les organisateurs puissent mettre le contenu à jour sans redéployer
- Carte du lieu avec **Leaflet** / Google Maps
- Interface construite avec Bulma + Buefy, indicateurs de chargement pendant l'arrivée des données

### Technologies
Vue 2 · Vue Router · Firebase / VueFire · Leaflet · Bulma / Buefy · Webpack

### Exécution locale
```bash
npm install
npm run dev
```

## English

Single-page website for **EVIC 2018**, a scientific conference hosted at Universidad de Santiago de Chile (USACH). It presents the event, invited speakers, program, competition and venue.

### Highlights
- Vue 2 SPA with Vue Router and smooth-scroll navigation between sections
- Speaker and program data served from **Firebase** (VueFire), so organizers could update content without a redeploy
- Venue map with **Leaflet** / Google Maps
- UI built with Bulma + Buefy, loading spinners while data arrives

### Stack
Vue 2 · Vue Router · Firebase / VueFire · Leaflet · Bulma / Buefy · Webpack

### Run locally
```bash
npm install
npm run dev
```
